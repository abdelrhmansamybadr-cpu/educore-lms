# LMS Deep Research — Features & Competitive Analysis
# All Major LMS Platforms: Functions, Options & Feature Map

---

## 1. MOODLE (Open Source — World's Most Used LMS)

### Student Features
- Dashboard with enrolled courses overview
- Course content: pages, books, folders, URLs, files, labels
- Activity types: assignments, quizzes, forums, wikis, glossaries, workshops, SCORM/xAPI packages
- Grade book with weighted categories
- Calendar with events and deadlines
- Messaging and notifications
- Progress bar and completion tracking
- Badges and certificates
- Accessibility: screen reader support, keyboard navigation
- Mobile app (Moodle App — iOS/Android)
- Offline access to course materials
- Portfolio (Mahara integration)

### Teacher Features
- Full course builder (sections, topics, weeks format)
- Quiz builder: multiple choice, true/false, short answer, essay, matching, drag-and-drop, cloze
- Assignment types: online text, file upload, video submission
- Rubric-based grading
- Plagiarism detection (Turnitin integration via plugin)
- Group management and group activities
- Attendance plugin
- Lesson module (branching scenarios)
- Workshop (peer assessment)
- Competency frameworks
- Bulk grade import/export (Excel/CSV)
- Course backup and restore
- Live session via BigBlueButton integration
- Course analytics (completion rates, activity logs)

### Parent Features
- Parent/guardian accounts (limited — via plugin)
- View child's grades and progress
- Messaging teachers

### Admin Features
- Multi-school/multi-tenant via Moodle Workplace or MoodleNet
- User management: bulk enroll, roles, cohorts
- Authentication: LDAP, SAML, OAuth, email
- Plugins marketplace (1000+ plugins)
- Custom themes and branding
- Language packs (120+ languages including Arabic RTL)
- Gradebook configuration
- Site-wide reports and analytics
- Payment gateway via Moodle Commerce (PayPal, Stripe)
- Course enrollment fees
- Custom roles and capabilities

### Unique Features
- Competency-based education framework
- Learning plans
- Workshop peer review
- SCORM 1.2 / 2004 / xAPI (Tin Can) / cmi5 support
- H5P interactive content (built-in)
- Open Badges (Mozilla)

### Weaknesses / Missing
- Outdated default UI (improving with Boost theme)
- Complex setup for non-technical admins
- No built-in live video conferencing (relies on plugins)
- Parent portal is weak (plugin-dependent)
- Financial management limited
- No transportation, canteen, or ERP features

## 2. CANVAS (Instructure) — Popular in US Schools & Universities

### Student Features
- To-Do list and activity stream
- Course modules (sequential content unlock)
- SpeedGrader annotations on submissions
- Video/audio submissions
- ePortfolio builder
- Peer review assignments
- Discussion boards with threading
- Collaboration (Google Docs, Office 365 integration)
- Canvas Studio (video recording and commenting)
- Inbox (messaging)
- Calendar with iCal export
- Mobile app (iOS/Android — excellent UX)
- Offline mode (limited)
- Accessibility: WCAG 2.1 AA certified

### Teacher Features
- Blueprint courses (master template courses pushed to sections)
- Question banks with item analysis
- New Quizzes engine (advanced question types)
- Rubrics (holistic, analytic)
- Learning mastery gradebook
- SpeedGrader (side-by-side submission and grade entry)
- Anonymous grading
- Outcomes/standards alignment
- Differentiated assignments (per student/group)
- Late policy automation
- Module prerequisites and requirements
- Course analytics (individual student activity)
- Conference (BigBlueButton built-in)

### Parent Features (Canvas Parent App)
- Separate parent app
- View child's grades, missing assignments, calendar
- Receive notifications
- Message teachers

### Admin Features
- SIS (Student Information System) integration via CSV or API
- Sub-accounts for departments/schools
- Custom roles
- Feature flags (enable/disable features per account)
- LTI (Learning Tools Interoperability) — connect any external tool
- Account-level analytics
- Catalog (course marketplace/enrollment pages)
- Canvas Data (data warehouse exports)
- SSO: SAML 2.0, CAS, LDAP
- Branding per sub-account
- Terms and enrollment periods

### Unique Features
- Blueprint Courses (master course → child instances)
- Canvas Studio (interactive video)
- New Quizzes with enhanced item types
- Learning Mastery Gradebook (standards-based)
- Canvas Credentials (digital badges + transcripts)
- Catalog (self-enrollment marketplace)
- Canvas Data (analytics pipeline)
- LTI 1.3 ecosystem (1EdTech certified)

### Weaknesses / Missing
- Expensive (SaaS only)
- No built-in fee payment per student
- No transportation or canteen
- Limited Arabic RTL support historically (improving)
- Parent app is read-only, no two-way full communication
- Complex LTI setup for smaller schools

## 3. BLACKBOARD / ANTHOLOGY

### Student Features
- Original Course View and Ultra Course View
- Content areas and learning modules
- Tests and surveys
- Grade Center
- Discussion boards
- Collaborate Ultra (video conferencing built-in)
- Ally (accessibility checker and alternative formats)
- Safe Assign (plagiarism detection — built-in)
- Mobile app (Blackboard Student)

### Teacher Features
- Ultra Course Design (modern card-based layout)
- Adaptive Release (content conditionally shown)
- Early Alert (flag at-risk students)
- Retention Center
- Performance Dashboard
- Tests with 17+ question types
- Rubrics
- Group management
- Anonymous grading

### Admin Features
- Building Block plugins
- SIS integration
- REST API
- Multi-institution management
- Reporting and analytics suite
- SSO enterprise (SAML, OAuth)

### Unique Features
- Ally (accessibility + alternative format generation)
- Safe Assign (built-in plagiarism)
- Collaborate Ultra (best built-in video conferencing)
- Adaptive Release (sophisticated content gating)
- Early Alert / Retention Center (student success)
- Predictive analytics (Blackboard Analytics)

### Weaknesses / Missing
- Very expensive
- Complex admin UI
- Legacy codebase (Ultra is the new redesign)
- No parent portal
- No mobile-first approach historically
- No financial or ERP features

## 4. GOOGLE CLASSROOM

### Student Features
- Stream (announcements + assignments feed)
- Classwork (organized topics)
- Assignment submission (Google Docs, Drive, links, files)
- Grades view (basic)
- Google Meet integration
- Google Calendar sync
- Mobile app (iOS/Android)

### Teacher Features
- Post announcements, assignments, questions, materials
- Return assignments with comments
- Grade in browser or mobile
- Reuse posts across classes
- Import questions from Google Forms
- Co-teachers
- Guardian summaries (automatic weekly/daily email to parents)
- Integration with all Google Workspace apps

### Admin Features
- Google Workspace Admin Console
- Automatic class creation from SIS (via API)
- Usage reports
- Provisioning
- Free (included with Google Workspace for Education)

### Unique Features
- Seamless Google Workspace integration
- Originality Reports (plagiarism via Google Search)
- Practice Sets (AI-powered adaptive quizzes)
- Add-ons marketplace
- Free tier for all schools

### Weaknesses / Missing
- Very basic LMS — not feature-rich
- No advanced gradebook
- No competency/standards tracking
- No built-in video conferencing (relies on Meet separately)
- No parent portal app (only guardian email summaries)
- No course catalog or enrollment management
- No financial features
- RTL/Arabic support is basic

- Insight analytics (powerful dashboards)

## GAPS & INNOVATION OPPORTUNITIES (Features No LMS Has Well)

1. **Full Multi-Currency Payment** — no LMS natively supports EGP, SAR, AED, GBP, USD per school
2. **Built-in Transportation Tracking** — real-time bus GPS for parents
3. **Canteen/Cafeteria Management** — meal ordering, dietary restrictions, balance top-up
4. **Mental Health & Wellbeing Module** — mood check-ins, counselor referrals, anonymous support
5. **AI Personal Tutor** — per-student AI assistant that knows their curriculum
6. **AI Lesson Plan Generator** — generates lesson plans from curriculum standards
7. **Predictive At-Risk Student Detection** — AI flags students before they fail
8. **School Event Management** — trips, sports days, concerts, ticketing
9. **Library Management Integration** — book loans, catalog, overdue alerts
10. **Multi-Curriculum in One Platform** — National (Egyptian/Saudi), American, British, IB simultaneously
11. **Offline-First Mobile App** — full offline mode with sync (critical for MENA)
12. **Alumni Network** — graduate tracking, university placement
13. **Scholarship & Financial Aid Module** — application and tracking
14. **Health Records & Nurse Module** — student health, medication, injury logs
15. **Staff HR Management** — contracts, leave, payroll integration
16. **Parent Teacher Conference Booking** — online scheduling with video
17. **Gamified Learning Map** — visual journey/map instead of list of courses
18. **Social Learning Feed** — academic social network within school
19. **Real-time Collaborative Whiteboard** — in live class
20. **Voice Assistant for Homework** — "Ask Alexa/Google" style for schoolwork
